📋 CONTENU DÉTAILLÉ:

1. PRÉREQUIS (lignes 9-25)
   • Installation PostgreSQL (Windows/MacOS/Linux)
   • Installation pgAdmin 4
   • Configuration mot de passe

2. ÉTAPE 1: LANCER PGADMIN (lignes 28-44)
   • Ouvrir pgAdmin 4 sur chaque OS
   • Première connexion dans le navigateur
   • Connexion au serveur PostgreSQL
   • Vérification icône verte

3. ÉTAPE 2: CRÉER LA BASE DE DONNÉES (lignes 48-69)
   • Clic droit sur "Databases"
   • Configuration onglet "General"
     - Nom: djerba_booking
     - Owner: postgres
   • Configuration onglet "Definition"
     - Encoding: UTF8
     - Template: template0
     - Collation: en_US.UTF-8
   • Sauvegarde

4. ÉTAPE 3: IMPORTER LE SCHÉMA (lignes 73-122)
   
   MÉTHODE 1 - Query Tool (Recommandé):
   • Ouvrir Query Tool sur djerba_booking
   • Ouvrir fichier backend/schema.sql
   • Vérifier le contenu (CREATE TABLE, INSERT)
   • Exécuter avec F5
   • Vérifier messages de succès
   
   MÉTHODE 2 - Copier-Coller:
   • Ouvrir schema.sql dans éditeur texte
   • Copier tout (Ctrl+A, Ctrl+C)
   • Coller dans Query Tool (Ctrl+V)
   • Exécuter

5. ÉTAPE 4: VÉRIFIER LES DONNÉES (lignes 125-156)
   • Rafraîchir la base de données
   • Développer: djerba_booking → Schemas → public → Tables
   • Vérifier 3 tables créées:
     - users
     - accommodations
     - bookings
   • Vérifier 8 hébergements dans accommodations
   • Option A: View/Edit Data (GUI)
   • Option B: Requête SQL SELECT *
   • Vérifier structure (Properties → Columns/Constraints)

6. ÉTAPE 5: CONFIGURER LE BACKEND (lignes 159-200)
   • Ouvrir backend/.env.example
   • Créer backend/.env
   • Configurer tous les paramètres:
     - PORT=5000
     - DB_HOST=localhost
     - DB_PORT=5432
     - DB_USER=postgres
     - DB_PASSWORD=votre_mot_de_passe
     - DB_NAME=djerba_booking
     - JWT_SECRET=généré
   • Générer JWT_SECRET avec node crypto
   • Sauvegarder

7. ÉTAPE 6: TESTER LA CONNEXION (lignes 204-250)
   
   Test depuis pgAdmin:
   • Requête simple: COUNT(*) → résultat: 8
   • Requête complexe: SELECT avec WHERE et ORDER BY
   
   Test depuis l'application:
   • cd backend && npm install
   • npm start
   • Vérifier "Connected to PostgreSQL database"
   • Tester API: http://localhost:5000/api/accommodations

8. DÉPANNAGE (lignes 253-310)
   • Password authentication failed → solution
   • Database does not exist → solution
   • Connection refused on port 5432 → solution
   • Relation does not exist → solution
   • Données ne s'affichent pas → solution

9. INFORMATIONS UTILES (lignes 313-347)
   • Voir informations serveur PostgreSQL
   • Sauvegarder la base (Backup)
   • Restaurer une sauvegarde (Restore)
   • Supprimer et recommencer (Delete/Drop)

10. RÉSUMÉ ET PROCHAINES ÉTAPES (lignes 350-382)
    • Checklist des 7 étapes
    • Commandes pour démarrer backend et frontend
    • URL de l'application

11. VOIR AUSSI (lignes 385-391)
